Molecular and Materials Modeling — August 2026 Homework
========================================================

Description
-----------

This repository contains my completed computational challenges for the
Molecular and Materials Modeling School, held on 26–27 August 2026 and
taught by Professors Miroslav Iliaš and Dipayan Sen from the Bogoliubov
Laboratory of Theoretical Physics (BLTP), Joint Institute for Nuclear
Research (JINR), Dubna, Russia.

The exercises use MOPAC, NWChem, Quantum ESPRESSO, Python, ASE, and MPI
to perform molecular and materials modeling calculations.

Each challenge directory contains its own ``README.rst`` file, descriping
input files, software details, execution instructions, and main results.
